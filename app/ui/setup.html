Как работает этот компьютер?

База клиники хранится на одном компьютере — сервере. Остальные компьютеры (ресепшн, кабинеты, директор) подключаются к нему по сети клиники. Интернет для этого не нужен.

Это сервер клиники

Здесь будет храниться база, отсюда идёт обмен с Dentist Plus. Компьютер должен быть включён, пока работает клиника. Лучше подключить его к ИБП.

Windows может спросить разрешение для сети — разрешите для частных сетей.
