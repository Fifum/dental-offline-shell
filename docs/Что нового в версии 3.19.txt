Dental Desk 3.19.0 — склад на телефоне без интернета, фото материалов

• Нет интернета — склад на телефоне
  работает по Wi-Fi клиники прямо
  с компьютером. Телефон в Wi-Fi
  клиники, программа на компьютере
  открыта.
• На телефоне: «Профиль» → «Склад
  через Wi-Fi клиники». Когда облако
  не отвечает, сверху появляется
  плашка — нажмите её. Вход тем же
  ПИН-кодом.
• Операции сразу приходят на этот
  компьютер, оттуда — в облако и на
  другие компьютеры клиники.
• Один раз телефон подключают через
  интернет («Подключить мой телефон»),
  дальше интернет не нужен.
• Без сертификата код материала
  фотографируют или вводят вручную.
  Сканер камерой — в режиме «Со
  сканером»: директор включает его
  в Склад → «Телефон», а на телефон
  один раз ставят сертификат клиники.
  Шаги для Android и iPhone — на
  странице по QR-коду.
• Фото материалов с телефона:
  в карточке материала —
  «Сфотографировать» или «Из галереи».
  Снимок появится в карточке на
  компьютере, без связи подождёт
  в очереди телефона.

В ПРОГРАММЕ
━━━━━━━━━━━━━━
• Склад → «Телефон» → «Без интернета
  — через Wi-Fi клиники»: адрес этого
  компьютера для телефонов, сколько
  телефонов он знает, переключатель
  «Со сканером» и QR-код страницы
  с сертификатом.
• Брандмауэр Windows не пускает
  телефоны — там же кнопка
  «Разрешить».
• «Мой профиль» — ссылка на этот
  раздел.
• «Зачем устанавливать сертификат
  клиники» — простыми словами,
  в программе и на телефоне.
• Нет связи с компьютером клиники —
  телефон предложит склад через
  интернет.
