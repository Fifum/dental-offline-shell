СПИСАНИЕ МАТЕРИАЛОВ ПО ПРИЁМАМ DENTIST PLUS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• «Склад» → «По приёмам»: завершённые приёмы Dentist Plus с их услугами и материалами, которые уходят по нормам списания (техкарта услуги — вкладка «Нормы списания»).
• По умолчанию это черновики: материалы списываются, когда сотрудник с правом «Склад: приход, списание» подтвердит приём — по одному или отмеченные сразу. Само ничего не списывается.
• Режим «Сразу» (кнопка «Настройки»): завершённые приёмы списываются автоматически, раз в 5 минут. Только приёмы с дня включения — более ранние остаются черновиками. Приём «в кресле» ждёт завершения или следующего дня.
• Один приём списывается один раз. Если на приём выставлен счёт в программе, материалы уже списаны по счёту — приём помечается «Списано по счёту». Два компьютера, списавшие один приём без сети, после синхронизации оставят одно списание.
• Любое списание можно отменить: материалы вернутся на склад, а приём автоматически больше не спишется (списать снова можно вручную). Можно пометить приём «не списывать» с причиной.
• Услуги приёма берутся из данных Dentist Plus. Если Dentist Plus их не передал, на экране так и написано — «нет данных из Dentist Plus», а услуги можно указать вручную. Можно также брать услугу, название которой совпадает с названием записи (включено, выключается в настройках).
• Подтверждение, отмена, «не списывать», услуги вручную и смена режима попадают в журнал действий; автоматические списания — от имени «Автосписание».

МЕСТА ХРАНЕНИЯ И ПЕРЕМЕЩЕНИЯ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• «Склад» → «Места хранения»: основной склад, кабинеты и филиалы. У кабинета можно указать кресло (как в Dentist Plus), у места — филиал.
• Перемещение между местами — документ с номером и историей; общий остаток клиники при этом не меняется. Кнопка «Добавить, чего не хватает до минимума» подставит недостающее.
• «Остатки»: переключатель «Все места» / одно место. Приход, списание и инвентаризацию можно провести по конкретному месту; списать больше, чем есть в этом месте, нельзя.
• Приём Dentist Plus списывается из кабинета своего кресла, затем — из места своего филиала, иначе — из места по умолчанию (настройки) или с основного склада. Счёт, выставленный в программе, списывает из кабинета своей записи.
• В карточке материала — остатки по местам, в «Движении» — место каждой операции и фильтр по месту.
• Пока мест нет, всё работает как раньше: всё лежит на основном складе.

СЕБЕСТОИМОСТЬ УСЛУГ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• «Бухгалтерия» → «Себестоимость»: по каждой услуге прайса — материалы по нормам × последняя цена закупки, лаборатория, прочие затраты, процент врача, себестоимость, маржа в рублях и процентах.
• Процент врача: свой у услуги, иначе общий процент клиники из настроек, иначе средний процент из схем оплаты врачей («Зарплата»).
• За месяц: сколько услуг оказано (по счетам программы и по списанным приёмам Dentist Plus), сумма по прайсу, себестоимость и маржа. Оплат Dentist Plus в его API нет, поэтому сумма — по ценам прайса.
• Во вкладке «Нормы списания» видно, на сколько рублей материалов уходит на одну услугу.
• Материалы в ОПиУ и финмодели — по закупкам (как было) или по списанию со склада за месяц. Во втором случае закупки в ОПиУ не входят, чтобы не считать материалы дважды. В подсказке у строки «Материалы» видны обе суммы.

ПРАВА И СИНХРОНИЗАЦИЯ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• Смотреть «По приёмам» и «Места хранения» — «Склад: просмотр»; подтверждать, отменять, перемещать и настраивать — «Склад: приход, списание». Себестоимость и материалы в ОПиУ — «Бухгалтерия».
• Места хранения, списания по приёмам, их настройки и себестоимость работают без интернета и передаются на все компьютеры клиники. Сотрудник в списаниях хранится по логину, поэтому на всех компьютерах виден один и тот же человек.
