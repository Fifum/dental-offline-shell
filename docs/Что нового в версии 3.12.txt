Dental Desk 3.12.0 — что нового

Обновления теперь приходят быстро и бесплатно. Программа скачивает только то, что изменилось в новой версии, а компьютеры клиники передают обновление друг другу по сети клиники: из интернета его скачивает один компьютер, остальные берут готовый файл у него за секунды. Оборванное скачивание продолжается с того же места.

━━━━━━━━━━━━━━
ТОЛЬКО ИЗМЕНЕНИЯ
━━━━━━━━━━━━━━
• В каждой версии теперь есть список всех её файлов с контрольными суммами. Программа сверяет с ним свои файлы и скачивает только изменившиеся — примерно 15 МБ вместо 116 МБ.
• Новая версия собирается рядом с установленной, и каждый её файл проверяется по подписанному списку. Затем программа, как и раньше, закрывается, сохраняет резервную копию и открывается уже новой версией.
• Если что-то не сходится — изменён файл программы, другая версия, повреждено само обновление, — программа без вопросов скачивает обновление целиком, как раньше.
• В окне обновления видно, сколько скачается: «только изменения, 15 МБ». Под полосой скачивания написано, откуда идёт файл: из интернета или с компьютера клиники.

━━━━━━━━━━━━━━
ПО СЕТИ КЛИНИКИ
━━━━━━━━━━━━━━
• Компьютер, который уже скачал и проверил обновление, раздаёт его остальным компьютерам клиники. Остальные сначала спрашивают соседей и только потом идут в интернет.
• Если обновление в эту минуту скачивает другой компьютер клиники, программа дожидается его и берёт готовый файл у него: одно и то же не скачивается из интернета дважды.
• Файл, полученный по сети, проверяется по контрольной сумме из подписанного обновления: испорченный или чужой файл не ставится. Компьютеры другой клиники файл не получат и подсунуть свой не смогут.
• Если в сети никого нет — обновление скачивается из интернета, как раньше.

━━━━━━━━━━━━━━
ДОКАЧКА
━━━━━━━━━━━━━━
• Если связь оборвалась, скачивание продолжается с того же места — и из интернета, и по сети клиники. Уже скачанная часть сохраняется даже после перезапуска программы.
• Кнопка «Повторить» после обрыва продолжает скачивание, а не начинает его заново.

━━━━━━━━━━━━━━
ВАЖНО
━━━━━━━━━━━━━━
• Обновление до версии 3.12 скачивается целиком, как раньше. Быстрые обновления «только изменения» начинаются со следующей версии.
• Раздача по сети клиники работает между компьютерами с версией 3.12 и новее: после этого обновления каждый следующий выпуск скачивается из интернета одним компьютером клиники.
